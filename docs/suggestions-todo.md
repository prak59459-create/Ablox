# 意見箱：つづきと、持ち主が決めること

ここに書いたものは、意見箱のルーティンが毎回見て、作れるものから作ります。

### ゲーム1つ1つの完成度を上げて ディテールを増やす（2026-10-08 の意見、段階で進める）

第1段階（2026-10-08）: 共通の部品（木・もみの木・家・店・街灯）に 飾りを足して、それを使う全マップを細かくしました。飾りは すりぬける（遊び方は変わらない）。

次の回から、上から順に1回につき 2〜3本ずつ:

1. 人気の定番（ゲーム一覧の 1〜25）から。ゲームごとに「見て分かる仕上げ」を足す: 地面の模様（道・草・砂のちがい）、入口の看板、建物の中の家具、スタート地点まわりの飾り。ブロックの数は 1本 2,500 まで（一覧の上限 5,000 の半分、iPad の速さのため）
2. 遊びの仕上げ: 遊び方の「？」とクエストが そのゲームの中身と合っているか、ごほうびの数字が 早すぎ・遅すぎないかを 自動プレイの結果で見直す
3. 音と演出: 勝ったとき・レベルアップ・レアを引いたときの 効果音とパーティクルを、まだないゲームに足す（`lib/kit.absc` に共通の関数を作って使う）
4. 共通の部品をもう1回: 岩（小石を足す）、道（歩道のふち）、さく（くい）。スクリプトが名前やタグで 探す部品（`blocks("rock")` など）は 部品の数を変えない
5. 全部 終わったら、ゲームごとに「何を足したか」を abloxgames の README に1行ずつ

### 全ゲームの不具合を見直して、直せるものは作り直す（2026-10-09 の意見、段階で進める）

第1段階（2026-10-09、Ablox 5.4）: Meme Heist のカーペットの ミームが 見えない・動かない のを直した。原因は エンジンで、`move_to` で長く動く どのゲームのキャラにも 効く（遠くの判定・とちゅう参加・とちゅうの変更・一定のはやさ）。135本を ロボットで 自動プレイして スクリプトのエラーが ないことを 確かめた。

第2段階（2026-10-09、Ablox 5.5）: カーペットの ミームが「買う」の場所に 見えないことがある、という報告を直した。動いているブロックを RealityKit の アニメーションに まかせず、毎フレーム スクリプトと同じ場所に 置く（`BlockTrips`）。ブロックより 先にとどいた 動きも すてずに とっておく。

次の回から、1回につき 4〜5本ずつ（ゲーム一覧の 1 から順に。上のディテールの段階と 同じ回に まとめてよい）:

1. ゲームごとに スクリプトを読んで「見て分かる不具合」を さがす: 動くはずのものが 動くか（`mv`/`move_to` の あとに すぐ `destroy` していないか、終点が マップの外でないか）、ラベルや ボタンが 重なっていないか、ゲームの「？」と 中身が合うか
2. 自動プレイ（`tools/build.sh --only N`）の ロボットに、そのゲームの主な遊び（買う・のる・戦う）を してもらい、お金や レベルが ちゃんと 増えるかを 見る。止まる・増えないものは 直す
3. Meme Heist の残り: 台の上のミームの「お金をうむ」表示が 遠くでも 見えるか、ぬすむ・合体・転生のあとで 台のミームが 消えないかを テストに足す
4. 直したものは ゲームごとに 1行、abloxgames の README と この文書に書く


### Last Survivor Games のゲームをふやす・100人に（2026-10-09 の意見、段階で進める）

第1段階（2026-10-09、abloxgames）: 参加者を 24人 → 100人（足りない分は NPC。NPC の上限 100 の中）。
ゲームの順番を「だるまさんがころんだ が最初 → まん中のゲームを ランダムに、残りが5人より少なくなるまで くり返す
（同じゲームは2回続けない。14ゲームで まだ多ければ そこで打ち切り）→ 最後は 決戦リング」に。
新しいゲーム: 🍪 型ぬき（⚪🔺⭐☂️、箱をえらぶ）・🔮 ビー玉あて（2人1組で 奇数か偶数か）・🥊 決戦リング（「ドン！」で おし出す。
なぐり合いではなく おし出しにした）。最後のタイルは まん中のゲームになり、半分が落ちたら終わり。つなひきは 50対50 でも床に並ぶ。

次の回から、上から順に:

1. 🏃 5人6脚レース（まん中のゲーム）: 5人ずつ横にならんで 足をつなぎ（いっしょに動く）、制限時間5分でコースを回りながら
   5つのミニゲームを順にクリア。1つずつ 別ファイルにして、まずは コースと「全員がそろって進む」しくみ + めんこ（紙のタイルを
   たたいて 裏返す）+ コマ回し（タイミングよく ひもを引く）の2つ
2. 5人6脚の残り3つ: 石あて（石を投げて 立っている相手の石を たおす）・石のお手玉（投げた石を 落とす前に 拾う）・
   羽根けり（羽根を 足で 落とさずに けり上げる回数）
3. 新しいゲームのクエストと実績、売店の道具（型ぬき用の「🪡 よく切れる針」= ひび1回ぶん守る など）
4. 自動プレイ（`tools/build.sh --only 78`）で、100人のショーが さいごまで 止まらずに 進むかを たしかめる
   （いまの ロボットの150秒では だるまさんがころんだ の先まで行かないので、テスト用に ゲームの順番を変えて 1本ずつ確かめた）

### iPhone の画面に合わせる（2026-10-13 の意見、段階で進める）

第1段階（2026-10-13、Ablox 6.4）: 画面の大きさの判定 `ScreenFit`（環境の `screenFit`）。iPhone では メニューの左の列を アイコンだけに、アバターの着がえ画面と 大きい地図を 画面に合わせた。

第2段階（2026-10-13、Ablox 6.5）: メニューの各ページの余白を `fit.gutter`（iPhone で 14）に。ワールド・ゲーム・プレイ・ルームのカードの最小の幅を `fit.cardMinimum(_:)` にして、iPhone でも 1列に入るように。

第3段階（2026-10-13、Ablox 6.6）: 遊ぶ画面。iPhone の横向きでは ジャンプと となりのボタンを 0.8倍にして はしに よせ（`fit.controlScale`・`fit.controlInset(_:)`）、右上の地図は 高さの 3分の1まで（`fit.cornerMap(_:)`）。

次の回から、上から順に:

1. 設定・ショップ・プロフィールの シートを iPhone の 縦向きで 見直す（横に並べた ボタンが はみ出さないか）
2. CI の Launch check に iPhone のシミュレータでも 起動して 各タブを開く ステップを足す

### 持ち主が決めること

- **AI の機能（操作の案内など）**（2026-10-13 の意見から）: 外の AI サービス（Groq など）を 呼ぶには、持ち主のアカウントと APIキーが 必要です。
  キーを アプリに 書きこむと、ソースが公開なので だれでも 読めて 使われてしまいます。作るなら、持ち主が サーバー（Firebase の Cloud Functions など、有料プラン）に キーを置き、
  アプリは そのサーバーだけに 話しかける形にします。子どもの書いた文が 外のサービスに送られるので、家族の設定で オンにしたときだけ にします。
  📝 意見の中に Groq の APIキーが 書かれていました（リポジトリには 書いていません）。そのキーは 使わずに、Groq のコンソールで 無効にしてください。

- **バックアップの封印を もっと強く**（2026-10-13 の意見から）: 6.3 で バックアップと セーブのファイルに 封印をつけ、手で書きかえたものからは コイン・アイテムが 戻らないようにしました。ただ 封印の鍵は アプリの中（ソースは公開）なので、ソースを読める人なら 作れます。もっと強くするには、バックアップを サーバー（Firebase の Cloud Functions など、持ち主のアカウントと 有料プランが必要）で 署名するか、コインを サーバーに 置く必要があります。

- **オリジナルの「ロープで ビルを わたる ヒーロー」のゲーム**（2026-10-12 の意見から）: 意見は 本物の映画のキャラクターだったので 見送りにしました。名前も見た目も オリジナルにした「ロープで ぶら下がって 街を 移動する」ゲームなら 作れます。作るなら、ロープで ぶら下がる 動き（エンジンの追加）から 段階で 進めます。
