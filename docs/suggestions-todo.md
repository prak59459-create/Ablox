# 意見箱：持ち主が決めること

- キャラクターの体の配置やアニメーションについての提案（外部リンク付き）。リンクの中身は見ていません。どのキャラの何を変えたいのかがはっきりしないため、内容を確かめてから決めてください。（2026-09-30）
- ワンタップアップデートが うまく動かない、という報告（Ablox 1.9）。iPad の Swift Playgrounds は、アプリが自分で自分を入れかえられないため、最後の「Install → Swift Playgrounds に送る」は手動です（docs/updates.md）。どの段階で止まるのか（ダウンロード・確認・インストール）が分からないので、設定 → 問題のレポート →「レポートをコピー」を送ってもらうと原因を調べられます。（2026-09-30）
